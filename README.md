# Pakistan Used Car Price Predictor

Predicting used car prices in Pakistan from 77k+ listings using Python and scikit-learn.

## Data
Kaggle: Pakistan Used Car Prices 2023 (link). Download the CSV and place it in `data/`.

## Data quality notes
- The `year` column contained the constant value 1905 for every row, so it was excluded.
